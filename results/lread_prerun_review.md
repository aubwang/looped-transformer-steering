Opposite signed eigenvalues can cancel; a positive C3 excess can coexist with near-zero tau and currently gets the same ZERO message. Likewise a strong *signed* deficit does not establish loss of a push: alpha can be strongly negative with large magnitude. Keep failed/incomplete sets ineligible for readings. In particular preserve completed Set A when Set B fails.

- **Coda gradients are correct.** `directions` differentiates only the last-position state, with the prefix detached, through coda and final norm. Contracting C with the linear head weight gives exactly the cotangent for C·logits. A constant head bias has zero derivative; embedding tying makes no difference with frozen parameters. The locally available model implementation defines a bias-free linear head. C2 token selection is intentionally held fixed during differentiation.
- **Self-gain and orientation are correct.** For T=1, `chain` returns the single VJP (its accumulated sum has one term); applying it again at the same x yields (J^T)^2 u. Stored x1[a,b]=<u_a,J^T u_b> matches `projected_alpha`, `rotation`, and `retention/compress`. Shapes are [context,direction,3,3] and [context,direction,direction]. JVP renormalization is undone by multiplying by the original norm; r is unit anyway. The independent central-FD adjoint test is meaningful, although relative error is noisy near zero inner products.
